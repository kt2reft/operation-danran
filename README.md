# オペレーション・ダンラン：ファミリー・クライシス

ブラウザで遊べる3Dパニック協力ゲームです。1〜4人で遊べて、同じ画面に集まっても、オンラインでも協力できます。
オンラインはアカウント不要で、招待リンクか4文字のコードで参加できます。

**▶ いますぐ遊ぶ：https://kt2reft.github.io/operation-danran/
**（GitHub Pages・オンライン協力はP2P方式）

## 入っているファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | ゲーム本体（これ1つで動きます） |
| `server.js` | 中継サーバー。ゲームの配信とオンライン通信をまとめて行います。追加パッケージは不要です |
| `package.json` | ホスティングサービス向けの起動設定（`npm start` で `server.js` が起動） |

## 公開のしかた（3通り）

### A. サーバー付きで公開する（おすすめ）

いちばん安定してつながる方法です。Node.js 18以上が動く場所なら、どこでも動きます。

**自分のパソコンで試す**

```
node server.js
```

ブラウザで `http://localhost:8080` を開きます。同じWi-Fiの人は `http://<このパソコンのIPアドレス>:8080` で参加できます。

**インターネットに公開する（例：Render）**

1. この3ファイルを GitHub のリポジトリに入れます。
2. Render で「New → Web Service」を選び、そのリポジトリを指定します。
3. Start Command を `node server.js` にします（Build Command は空でかまいません）。
4. 発行された `https://〜.onrender.com` を友だちに送れば、そのまま遊べます。

WebSocket が使える Node.js ホスティング（Fly.io、Railway など）でも同じように動きます。
無料プランは、しばらくアクセスがないと停止し、次に開いたときの起動に少し時間がかかることがあります。

### B. `index.html` だけを置く（サーバーなし）

GitHub Pages や Netlify などに `index.html` だけを置いても、オンライン協力で遊べます。
この場合は P2P（WebRTC）で、ホストのブラウザと参加者のブラウザが直接つながります。

- 相手を見つける仲介には、PeerJS の公開サーバー（無料）を使います。
- 会社や学校のネットワーク、一部のモバイル回線では、つながらないことがあります。そのときは A の方法を使ってください。
- TURN サーバーを持っている場合は、`index.html` 内の `CONFIG.ice` に設定すると、つながりやすくなります。

### C. `index.html` を置き、別の場所のサーバーにつなぐ

A のサーバーを別に立てている場合は、ページのURLに `?server=` を付けるとそのサーバーを使います。

```
https://example.github.io/danran/?server=wss://〜.onrender.com/ws
```

`index.html` 内の `CONFIG.server` に書いておけば、URLに付ける必要はありません。

## オンラインでの遊び方

1. ホストが「部屋を作る」を押します。
2. 表示された招待リンクを送るか、4文字のコードを伝えます。
3. 参加者はリンクを開くか、コードを入力して「コードで参加」を押します。
4. 各自がキャラを選び、ホストがステージを決めて「団らん開始」を押します。

- ゲームの計算はホストのブラウザが行います。ホストがページを閉じると部屋も終わります。
- 1部屋は最大4人です。ホスト側で同じ画面の協力プレイ（コントローラー・キーボード2人）と組み合わせることもできます。
- 満員やプレイ中に入った人は、次のラウンドから参加できます。
